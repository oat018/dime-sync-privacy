dime-sync — Privacy Policy

dime-sync is a personal automation script used only by its owner. It is not offered to the public.

What it accesses

With the owner's permission, it reads (read-only) emails sent by the owner's brokerage to the owner's own Gmail account, and writes the extracted data into a Google Sheet owned by the owner.

How data is used and shared

Data is used only to build the owner's personal records. It is not sold, shared with, or transferred to any third party, and is not used for advertising.

Storage

No data is stored outside the owner's own Google account. Attachments are processed in memory during each run and discarded.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
